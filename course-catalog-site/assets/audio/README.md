# Background music — testimonial video pipeline

Two royalty-free tracks by BlueTreeAudio, converted from the original WAV to
128kbps MP3 to keep repo size down (originals: ~34MB and ~28MB WAV → ~2MB and
~1.7MB MP3, no audible quality loss for background-music use).

- `blueprint-for-excellence.mp3` — source: "01. Blueprint for Excellence"
- `rising-ambitions.mp3` — source: "08. Rising Ambitions"
